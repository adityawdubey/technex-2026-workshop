# Problem 3: The Event Planning Concierge

## Objective

Coordinate specialized agents and combine their work into one useful response.

## Task Statement

Build an AI assistant that helps a user plan an event, such as a workshop, birthday celebration, or college meetup.

The user provides the event type, location, number of attendees, and budget. A coordinator identifies missing details and delegates relevant tasks to specialists, such as:

- **Venue specialist:** Suggests suitable venue options.
- **Budget specialist:** Estimates and checks expenses.
- **Schedule specialist:** Creates an event agenda.

The coordinator combines their recommendations into one consistent plan. If suggestions exceed the budget or conflict with each other, it should explain the issue and propose an adjustment.

Use sample venues and prices. **No real bookings or payments are required.**

## Expected Output

A consolidated event plan containing:

- Venue suggestions.
- A budget breakdown.
- An event schedule.
- Any assumptions or unresolved issues.

## Implementation

You may use any programming language, AI model, or orchestration framework.
